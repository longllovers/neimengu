# 内蒙古县级 Shapefile 裁剪需求说明

## 1. 输入

- 县界：`00县边界/15_县边界.shp`。
- 县代码：优先读取 `area_code` 并取前六位。
- 县名：优先读取 `area_name`。
- 专题数据：递归扫描用户指定根目录下所有子目录中的 `.shp`。
- 输入目录后续会增加 SHP，默认通过 SQLite 索引的 `auto` 模式增量更新。

## 2. 输出

- 每个县合并输出一个 Shapefile。
- 默认文件名：`六位县代码_县名称.shp`。
- 必须同步生成 `.shx`、`.dbf`、`.prj`、`.cpg` 配套文件。
- 输出字符编码为 UTF-8。
- 已有非空结果默认跳过，可选择覆盖。

## 3. 持久化空间索引

- 第一次运行递归扫描 SHP，读取投影、空间范围、几何类型和要素数量。
- 将范围转换为 WGS84 后写入 SQLite RTree。
- 文件组签名包含 `.shp`、`.shx`、`.dbf`、`.prj`、`.cpg` 等文件的大小
  和修改时间。
- `auto` 增量更新新增、变化和删除项。
- `skip` 直接复用已有索引。
- `rebuild` 完整重建。

## 4. 单县处理流程

1. 读取县界并转换为 WGS84。
2. 用 RTree 查询与该县范围相交的输入 SHP。
3. 将县界分别转换到每个输入 SHP 的坐标系。
4. 逐要素做真实几何相交和裁剪。
5. 合并输入字段，并将结果统一转换到输出坐标系。
6. 在临时目录生成完整 Shapefile 文件组。
7. 配套文件就绪后发布到最终输出目录，主 `.shp` 最后发布。

## 5. Web 页面

- 保留原页面相似的路径、索引模式、指定县、并发控制、进度、逐县状态、
  实时终端和停止功能。
- 页面只保留矢量裁剪需要的路径、索引、处理范围、并发和覆盖参数。
- Windows UNC 输入路径在 Linux 服务端自动转换为实际挂载路径。
