# 县级 Shapefile 批量裁剪

本项目递归扫描输入目录及其所有子目录中的 `.shp`，建立可增量更新的
SQLite RTree 空间索引，然后按照内蒙古县界裁剪数据。每个县的所有相交输入
会合并为一个新的 Shapefile。

默认输出文件名：

```text
150102_新城区.shp
```

同时生成 Shapefile 配套文件：

```text
150102_新城区.shp
150102_新城区.shx
150102_新城区.dbf
150102_新城区.prj
150102_新城区.cpg
```

## 环境

推荐使用已有的 Linux Conda `qgis` 环境。程序依赖 GDAL 的 Python
`osgeo` 模块和 ESRI Shapefile 驱动。

```bash
conda activate qgis
```

## 命令行运行

```bash
python clip_counties.py \
  --shp-dir "/media/cangling/nas_folder/专题2_农作物种植用地遥感测量/加密0711_乌兰察布-道_已全部完成并解密/完成成果解密" \
  --boundary "./00县边界" \
  --output-dir "./县级SHP裁剪结果" \
  --index "./shapefile_index.sqlite" \
  --index-mode auto \
  --workers 4 \
  --cpu-percent 75
```

输入目录会递归扫描，子目录中的 SHP 也会被发现。

## SQLite 索引模式

- `auto`：默认。扫描输入目录，仅重新读取新增、变化的 SHP，并删除已不存在
  文件的旧索引。
- `skip`：完全跳过目录扫描，直接使用已有索引。
- `rebuild`：清空并完整重建索引。

索引带有内部版本号。旧版索引若使用过不加密的四角投影范围，下一次选择
`auto` 时会自动完整重建，避免漏选位于弯曲投影边缘的源 SHP。

索引变化判断同时考虑 `.shp`、`.shx`、`.dbf`、`.prj`、`.cpg` 等文件，
因此修改属性表或投影文件也会触发更新。

## 常用参数

- `--county 150102`：只处理一个县，可重复指定。
- `--overwrite`：覆盖已有县级 Shapefile 文件组。
- `--workers 4`：允许同时处理的最大县数。
- `--index-workers 4`：并行读取新增或变化 SHP 元数据的线程数。
- `--name-template "{code}_{name}.shp"`：输出文件名模板。
- `--temp-dir /data/temp`：指定临时目录。

默认断点续跑：已有且非空的 `.shp` 会直接跳过。

## 数据处理约定

- 输入 SHP 可以使用不同投影，程序会将县界转换到各输入数据的投影后裁剪，
  最终统一为该县第一份候选数据的投影。
- 输出字段是相交输入 SHP 字段的并集。
- 点、线、面数据不能混在同一次输出中。如果同一个县的候选数据同时包含多种
  几何类别，该县会明确报错，应把点、线、面输入拆开运行。
- 没有坐标系定义（缺少有效 `.prj`）的输入无法建立索引，并会写入日志。

## Web 控制界面

```bash
conda activate qgis
python clip_counties_web.py
```

默认监听：

```text
http://运行脚本的电脑IP:9007/
```

页面提供路径、索引模式、处理范围、并发数、总体进度、逐县状态和实时脚本输出。

右侧底部带有“县级结果预览”：全部县处理结束后，扫描输出目录并一次性显示
所有已有县级 SHP，使用项目目录中的 `SimHei.ttf` 标注已有成果的县代码与县名。
支持鼠标滚轮、加减按钮缩放，放大后可拖动。县界、全部生成结果和标注均直接
绘制为纯 SVG，不依赖临时图片文件。

结果预览默认关闭，以免读取大型 SHP 和构建 SVG 占用额外时间。勾选左侧渲染
选项后，逐县处理中不会渲染，只有整个任务结束时才统一渲染一次；任务结束后再
勾选也可以。预览先用红色绘制全部县界，再把所有生成 SHP 的实际矢量覆盖范围
用深色叠加到红色底图上；不使用整县绿色状态层，以免遮盖真实成果分布。

为避免把数十万或数百万个原始节点逐个写进 SVG，全部成果先由 GDAL 在内存中按
两倍显示分辨率聚合成覆盖掩膜，再用游程编码转换为一个紧凑的纯 SVG 路径。不生成
PNG 或临时图片，能显著缩短服务端生成时间和浏览器解析时间；总览用于查看整体覆盖，
不替代 GIS 软件中的原始精度检查。

“停止任务”会立即终止裁剪主进程及其全部子进程；Linux 在短暂等待后会对仍存活的
原进程组执行强制结束。页面收到真实退出事件后才显示“任务已停止”。

页面默认输入目录为：

```text
\\10.10.10.11\data\专题2_农作物种植用地遥感测量\加密0711_乌兰察布-道_已全部完成并解密\完成成果解密
```

在 Linux 服务端启动任务时，页面会自动将
`\\10.10.10.*\data\...` 转换为 `/media/cangling/nas_folder/...`。
