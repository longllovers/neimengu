# 县级作物 Shapefile 拆分页面

页面使用 Python 标准库 `ThreadingHTTPServer`，多个浏览器标签页可独立并行运行任务。每个标签页拥有独立任务 ID、状态和日志。拆分任务在后台线程中运行，页面通过 JavaScript 仅增量更新日志和运行状态，不更新输入框。

不同输出文件夹的任务可以并行运行。服务器会锁定正在使用的输出目录；如果另一个标签页尝试同时写入同一输出目录，任务不会启动，并会提示等待或更换目录。任务成功或失败后都会自动释放目录锁。

## 使用

```powershell
.\.venv\Scripts\python.exe app.py
```

浏览器打开 <http://127.0.0.1:8000>，填写以下空白输入框后点击“运行”：

- 源地块 shp：待拆分的地块矢量；
- 输出文件夹：每个“县 × 作物”组合会生成一组 shp 文件；
- 市名称：只处理指定城市所属县，多个城市用中文分号 `；` 或英文分号 `;` 分隔，例如 `赤峰市；通辽市`。
- 作物分类定义：每行使用 `编号=作物名称` 格式，默认填入 1–7 的作物映射，可按任务编辑。

县界路径不需要在页面输入。程序会自动从 `app.py` 所在目录下的 `00县边界` 文件夹读取第一个 `.shp` 文件，当前目录结构对应 `00县边界\15_县边界.shp`。
县名字段固定使用 `area_name`，地块作物字段固定使用 `class`，均不需要在页面输入。

页面输入的源 shp 和输出文件夹允许使用 Windows 网络共享路径。后端会自动将反斜杠转换为 `/`，并进行以下 Linux 挂载路径映射（服务器末段支持 `1`–`255`）：

| Windows 网络共享 | Linux 挂载路径 |
|---|---|
| `169.254.51.x/data` | `/media/cangling/nas_folder` |
| `169.254.51.x/新建卷` | `/media/cangling/xinjianjuan` |
| `169.254.51.x/datadisk2` | `/media/cangling/EAGET` |
| `169.254.51.x/新加卷` | `/media/cangling/xinjiajuan` |

程序会将地块与县界做几何相交裁切，跨越县界的地块会分别裁入对应县的结果。`class` 对应关系如下：

| class | 作物 |
|---:|---|
| 1 | 春玉米 |
| 2 | 中稻 |
| 3 | 大豆 |
| 4 | 春小麦 |
| 5 | 马铃薯 |
| 6 | 油菜 |
| 7 | 向日葵籽 |

终端只显示脚本任务日志，不显示 HTTP 访问日志。输出文件名格式为 `县名__作物名.shp`（如 `某县__春玉米.shp`），同组 shp 保留源地块的全部属性。

每个任务使用 5 个工作线程并行计算地块与县界的空间相交，工作批次为 20,000 条。完全位于县内的地块会跳过昂贵的裁切运算，只有跨县地块才执行几何相交。写入操作统一由任务主线程执行，并按每组 500 条批量写入，因此不会有多个线程同时写同一个 shp。

输出结果按县存入“矢量成果/原始”目录。例如页面输出文件夹填写 `D:\拆分结果\赤峰市` 时，阿鲁科尔沁旗的结果保存在 `D:\拆分结果\赤峰市\阿鲁科尔沁旗\矢量成果\原始`，文件名仍为 `阿鲁科尔沁旗__作物名.shp`。

> Shapefile 不是单个文件，复制结果时请同时复制同名的 `.shp`、`.shx`、`.dbf`、`.prj`、`.cpg` 等配套文件。
