# 图斑任务三批分发脚本

## 需求规则

- 递归处理指定根目录下的全部 SHP，以 `QXMC` 为县级单位，每县独立分 3 批。
- 分配前先把 `FCBM` 为 `0`（含字符型 `0` 和数值型 `0`）的值改成字符 `0000`。
- 第一优先级是组合单位完整：在同一个 `QXMC` 县内，`YZCHBM + FCBM` 相同的全部图斑构成一个不可拆分单位，必须进入同一批次；不同县的相同组合视为不同单位。
- 第二优先级是空间距离：以组合单位内全部图斑的平均空间位置作为单位中心，连接彼此最近的单位，再切成三个相对连续、集中的片区。
- 三个批次的单位数差控制在单位总数的约 5% 内，小县至少允许相差 1；在满足该范围的方案中优先选择最明显的空间边界。
- 图斑数量不参与分配方案选择，只在日志和 CSV 中保留结果统计。
- `XZMC`、`CUNDM` 只用于逐镇、逐村日志统计，允许拆分。
- 每县总单位数不超过 10 时全部进入批次 1；11–20 个单位时划分批次 1、2；超过 20 个单位时划分批次 1、2、3。
- 在原 SHP 中新增或重算整数型字段 `批次`，值为 `1`、`2`、`3`。
- 输出 UTF-8 详细日志和可直接用 Excel 打开的汇总 CSV。

算法为“组合单位 + 动态均衡空间分区”：每县先按 `YZCHBM + FCBM` 聚合，组合内图斑绝不拆分；再依据单位总数决定分为一、二或三个批次。需要分区时，用组合中心构建最小生成树，在单位数差约 5% 的约束内选择距离最大的空间边界；若邻近树无法直接得到均衡分区，则沿 72 个空间方向尝试等量切分，选择内部距离最紧凑的方案。图斑数量完全不参与算法。

## 使用方法

请在当前项目目录运行：

```powershell
# 1. 推荐先试算：只生成日志，不修改 SHP
.\.venv\Scripts\python.exe .\distribute_batches.py .\10个

# 2. 正式执行：写回原 SHP，并在各 SHP 旁自动备份原整套文件
.\.venv\Scripts\python.exe .\distribute_batches.py .\10个 --execute
```

其他选项：

```powershell
# 正式执行但不备份（不推荐）
.\.venv\Scripts\python.exe .\distribute_batches.py .\10个 --execute --no-backup

# 指定字段名或日志目录
.\.venv\Scripts\python.exe .\distribute_batches.py .\10个 --field 批次 --log-dir 日志
```

正式模式不是简单地直接覆盖：脚本先在同目录写临时 SHP，复读并验证要素数、字段和值均正确后，才替换原文件。默认备份目录名形如 `原文件名_分发前备份_20260806_120000`。

> SHP 的 DBF 字段名最多 10 字节。脚本保持使用 UTF-8；字段名采用 `批次`，在 UTF-8 下占 6 字节，不会被截断，也不会改变原属性的字符编码。

## 日志内容

- 每个 SHP 的开始、完成、失败和写入校验结果；
- 每县三批数量、最大数量差、跨批镇数、跨批村数；
- CSV 以单位为主要统计，先输出 `总单位/单位批次1-3/单位数差/跨批单位数`；`总图斑数/图斑批次1-3/图斑数差` 仅作附加信息放在表格最后；
- 每个镇及每个村分别落入三个批次的数量；
- 空几何、无效几何、字段缺失、写入失败及自动恢复信息；
- `分发汇总_*.csv` 汇总所有文件和县的关键指标。
